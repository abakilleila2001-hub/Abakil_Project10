# Income Tax Calculator

## What It Does

This Flask app calculates estimated income tax. Enter an income and click Calculate to see the tax based on the three brackets used in the project.

## Built With

Python
Flask
HTML
CSS

## How to Run It

1.Open a terminal in the project folder.
2.Install Flask with `python -m pip install flask`.
3.Start the app with `python app.py`.
4.Open `http://127.0.0.1:5000` in your browser.

## Screenshot Description

On the home page, type your income and click Calculate. The three tax brackets are listed below the form. The results page shows how much income you entered and how much tax the app calculated. Click Go back to try another amount.
